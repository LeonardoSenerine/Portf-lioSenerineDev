# senerine.dev

Portfólio de Leonardo Senerine: sites e aplicações sob medida.

Next.js 16 (App Router) com rotas em português e inglês (`/pt` e `/en`), tema claro e escuro e animações com [Motion](https://motion.dev).

## Rodando localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Onde editar

- `src/content/dictionaries.ts`: todos os textos, em português e inglês
- `src/content/projects.ts`: projetos, links e capturas (em `public/work/<projeto>/`)
- `src/content/site.ts`: contatos e redes sociais
